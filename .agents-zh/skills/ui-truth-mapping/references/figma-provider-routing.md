# Figma 提供方选择

在采集 Figma 证据前执行，包括已授权的 Stage 4 修复。`none`、`existing`、
`runtime-baseline` 若不需要 Figma 证据，则不要求配置 Figma 工具。
此规则不增加 schema 字段或检查点。

## 选择一个提供方

检查当前会话的技能及可调用、可发现的 MCP 工具。只有技能名称不代表连接可用；
针对用户提供的节点做有界只读探测，核验认证、文件权限和所需读取能力。
区分未安装与已安装但未连接/未授权；没有探测结果不能声称可用。

| 用户指定 | 可用提供方 | 行动 |
|---|---|---|
| TemPad | 任意 | 使用 TemPad；不可用则解决其配置，禁止静默替换为官方 Figma。 |
| 官方 Figma | 任意 | 使用官方 Figma；不可用则解决其配置，禁止静默替换为 TemPad。 |
| 未指定 | 只有 TemPad | 使用 TemPad。 |
| 未指定 | 只有官方 Figma | 使用官方 Figma。 |
| 未指定 | 两者都有 | 默认使用 TemPad。 |
| 未指定 | 两者都没有 | 询问是否自动安装；解决前不采集证据。 |

用户明确选择优先于所有默认值。指定了不支持或有歧义的提供方时先澄清，不能自行
指派。简短告知选择结果，表格已能决定时不重复询问。在现有 `progress.md` 或
`decisions.md` 记录提供方、所加载技能的身份/来源、探测结果和限制，保留原始
Figma 节点及版本来源。一次证据采集中不能静默混用提供方。工具报错时停止依赖
该证据的工作，诊断后按该提供方文档恢复，切换前询问用户。缺少访问权限不允许
猜 UI、仅凭截图重建、伪造资产或降级为 runtime-baseline。

## 缺少配置

两者均未安装时，询问一次是否自动安装，说明提供方、可信来源和安装范围。
未指定偏好时建议 TemPad，同时允许选择官方 Figma。明确指定的提供方缺失时，
只提议安装该提供方。必须获得明确安装同意；开发授权和 CP-UI 不等于安装授权。
用户拒绝后，停止受影响的交付流程，记录阻塞，不继续实现或冻结。未回答不等于
同意；已有拒绝在用户改变决定前持续有效。

同意后，使用环境支持的安装器及经过核验的发布者说明，安装所选技能/插件并配置
MCP 连接。先检查安装状态，禁止编造包 ID、URL 或 shell 安装命令。仅安装 Markdown
不等于 MCP 已配置。如果不支持自动配置，说明需要的手工步骤并保持阻塞。认证、
Figma 权限或宿主重启可能需要用户操作；恢复前再次验证连接。不要通过重装已安装
的提供方解决权限问题，也不要自动把两套都安装。

## 各提供方的证据采集

- **TemPad：** 有对应已安装技能时读取其真实来源；`get_code` 读取作用域节点，
  `get_structure` 解决层级/几何歧义。TemPad `data-hint-*` 规则仅用于此分支。
- **官方 Figma：** 在 `get_design_context` 前加载官方插件的
  `figma:figma-design-to-code` 技能，或环境中经过核验的对应技能。不要与同名但
  非官方的 TemPad `figma-design-to-code` 混淆。遵循已安装技能/工具契约，包括其
  要求的 `skillNames`。先读取作用域设计上下文，metadata 和 screenshot 只能补充，
  不能替代。返回或需要动效时加载官方动效指南；调用 `use_figma` 前加载
  `figma-use`。未经用户单独授权，不得写入 Figma 文件。

两条路径均向 `ui-truth-mapping` 提供证据；Stage 2 归属、真实宿主实现、来源与资产
保真、coverage、PNG/GIF 审阅及冻结门槛仍由它负责。生成的 React/Tailwind 只是参考，
不能做成平行预览再移植到 Flutter/Android。需要持久化资产时保存真实导出的字节，
提供方 URL 会过期。Stage 4 默认使用冻结组件和确认预览；选择提供方不等于授权
重新采集或解冻。
