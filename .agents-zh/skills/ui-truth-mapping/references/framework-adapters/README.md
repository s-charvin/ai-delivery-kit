# 框架适配器参考

UI 真值映射 skill 定义框架无关的治理契约。本目录的适配器是宿主框架的
实现参考，可选且可互换。适配器必须遵守核心规则：真实宿主渲染、确定性
捕获、证据绑定、临时产物清理，以及独立的动效确认。

使用适配器前：

1. 识别宿主框架及其现有官方渲染测试链路。
2. 确认适配器的捕获和编码链路已经受宿主项目支持，或记录允许它的明确
   项目决策。
3. 适配器只负责测试/捕获机制；生产组件必须遵守宿主项目自身的架构和
   依赖。

每个适配器都应说明原生测试入口、真实组件触发方式、静态和动态捕获、时序
与编码语义、解码校验、临时产物清理、已知限制，以及证据字段映射。
